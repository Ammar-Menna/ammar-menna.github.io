# دعوة فرح إلكترونية

**عمار ومنة — 4 نوفمبر 2026، الساعة 7 مساءً، قاعة التراث.** (نسخة من دعوة مهند ومريم بنفس الشكل)

مشروع منفصل تماماً عن سيستم المحل — ملف `index.html` + `door.jpg` (باب القلعة) + `couple.jpg` (صورة العروسين — تصوير Frog Studio) + `music.mp3`.

## الشكل
- مدخل: باب قلعة خشب بمسامير دهب وسجادة حمرا (`door.jpg` 900×1600). الضلفتين متقصوصين من الصورة ويتفتحوا لجوه، وورا الباب صورة عمار ومنة جوه القوس
- بعد ما الباب يتفتح الصورة بتملا الشاشة مع الأسماء والتاريخ حوالي 4 ثواني، وبعدها الدعوة. لو الضيف ضغط وهو بيتفرج بتعدّي على الدعوة على طول
- بعدها 5 صفحات زي الستوري (خطوط فوق) بديزاين القلعة: حيطة حجر غامقة، قوس دهب فوقه وردة زي اللي فوق الباب، مشعلين نارهم بتترعش في الركنين، شرار نار طالع، ختم شمع أحمر بأول حرفين من الاسمين، وشرايط حمرا للعناوين. كل ضغطة بتقلب الصفحة زي الكتاب:
  1. الأسماء والتاريخ  2. العدّاد  3. الآية  4. الشكر  5. الميعاد والمكان والختام (صفحة اللبس اتشالت بطلب صاحب الدعوة)
- الضغط يمين/وسط الشاشة = الصفحة الجاية، الثلث الشمال = اللي قبلها، أو السحب بالصباع

## تعديل البيانات
افتح `index.html` وابحث عن `const CONFIG = {` — غيّر الأسماء والتاريخ والقاعة من هناك بس.

## الموسيقى
- `music.mp3` — River Flows in You (Yiruma) — ملف من صاحب الدعوة، والأغنية حقوقها محفوظة لـ Yiruma (اختيار صاحب الدعوة وعلى مسؤوليته)
- بتحاول تشتغل أول ما اللينك يتفتح؛ لو المتصفح منعها (أغلب الموبايلات بتمنع) بتشتغل مع أول لمسة
- لتغييرها: حط ملفك جنب index.html واكتب اسمه في `music` جوه CONFIG
